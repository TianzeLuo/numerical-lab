# 4.6 谱方法与伪谱：它会怎样骗你

这一章的每个数字都在本仓库里**实测**过：来自 `tests/4.6/` 的断言记录（`tools/run_asserts.py`
生成的 `chapters/4.6/asserts_report.md`）、四个可视化帧的 meta 字段，以及若干一次性探针。
没量过的说法一律不写。

---

## 1. "谱方法收敛得快" —— 快是光滑性的红利，不是方法的属性

**现象**：`sin(3x) + 0.5cos(7x)` 的谱微分，`n = 16` 与 `n = 64` 的相对误差分别是
**4.66e-15** 与 **1.01e-14**——误差与 `N` **无关**，因为它就是舍入级：三角多项式的谱微分
是**恒等算子**，误差是 `u` 的量级，不是"非常小"。

**实测（反面）**：同一个 `fourier_derivative` 作用在锯齿剖面上，`max|du/dx|` 在
`n = 32 / 64 / 128` 上是 **6.73 / 13.80 / 27.92**——随 `N` **线性增长**。
Gibbs 层的厚度是 `O(1/N)`，导数幅度自然是 `O(N)`，所以"加密网格"让导数**更差**。

**正确判据**：先问数据光滑不光滑，再谈精度。可执行的检查是"误差随 `N` 下降的速度"，
而不是"某一次的误差很小"。

---

## 2. 拿双对数拟合出的 `p` 当"指数收敛"的证据

**现象**：默认帧（`basis=fourier`、`profile=analytic`、`n=64`、`rho=0.6`）对 `|a_k|`
做双对数最小二乘，窗口 `k∈[4,32]` 上得到 **p = -7.129、R² = 0.938**。这个 `p` 比任何
代数衰减都陡，很容易被当成"指数收敛"的证据。

**实测**：同一条曲线的**局部斜率**（`meta.slope_first → slope_last`）从 **-0.737**
一路走到 **-3.942**；把窗口换成 `k∈[2,8]/[8,16]/[16,32]`，三段平均斜率是
**-3.06 / -6.64 / -12.77**——每段至少再陡 **3.6**。指数衰减的局部斜率**一直在变**，
代数衰减的局部斜率是**常数**。

**正确判据**：看 `meta.ratio_smooth_first → ratio_smooth_last`（默认帧实测
**0.143 → 4.08e-4**，每加倍再乘一个更小的数），而不是某个 `p` 值。
单看 `p` 一定会被"拟合窗口"骗：窗口是断言的一部分。

---

## 3. 对间断数据期待"指数收敛"

**现象**：锯齿 / 方波是教材里的标准测试函数，看起来"就一个跳变"。

**实测**：`fourier_convergence("jump", N)` 的 `L∞` 逼近误差在 `N = 16 / 256` 上是
**1.9078 / 1.8022**（比值 **1.06**，即**不下降**）；Chebyshev 侧的 `sign(x)` 是
**1.9944 / 1.9540**。Gibbs 过冲的极限是 `(2/pi)Si(pi) - 1 = 0.1789797`，
`K = 4 / 64 / 1024` 时实测 **0.182327 / 0.178918 / 0.178391**——它在**收敛到一个非零常数**，
加密网格只把振荡**压窄**，不把幅度变小。

**正确判据**：间断数据的误差下界是"跳变量的百分之几"，与 `N` 无关；
谱系数按 `k^-1`（跳变）或 `k^-2`（尖角）代数衰减（实测 **-0.9921** / **-1.9840**，
窗口 `k∈[8,48]`，`R² ≥ 0.9999`）。要指数收敛就得先让数据光滑（滤波、重构、或换坐标）。

## 4. 零点模态伪造斜率

**现象**：采样的方波"偶次谐波应当为 0"，于是拟合时把它们一起丢进最小二乘。

**实测**：`N` 点网格上的方波，跳变正好落在节点上，偶次谐波**不是 0 而是常数 `1/N`**
（`N = 64` 时每个都是 **0.03125**），拟合被这排常数点拖成 **p = -0.848、R² = 0.346**。
Chebyshev 侧的 `runge` / `|x|` 是偶函数，奇次系数**恰好**为 0（实测 **2.7e-16** /
**7.8e-16**），不筛就直接算局部斜率会得到 **+56** 这种正斜率。

**正确判据**：先筛掉低于 `1e-12 * max|a_k|` 的模态再拟合（`modal_decay_fit` 的
`n_zero_dropped`、帧的 `coeff_floor_mask` 就是这个），并且**在读数里写明筛了几个**。

---

## 5. 把"混叠误差"和"截断代价"混成一笔账

**现象**：写"去混叠把误差从 4e-2 降到 1e-16"，看起来是一次巨大的改进。

**实测（`N = 128`、输入谱 `|a_k| = k^-decay`、`decay = 1`，四项独立测量）**：

| 量 | 实测 | 含义 |
| --- | --- | --- |
| 混叠（朴素乘积 vs 全带参照） | **1.196e-2** | 折返真的污染了多少 |
| 其中落在保留带 `|k|<=N/3` | **2.67e-3** | 有用频段被污染的部分 |
| 2/3 截断代价（截断参照 vs 全带参照） | **3.740e-2** | 方法主动丢掉的 |
| 只补零到精确 3N/2、不截断 | **7.76e-5** | 保留带内几乎无混叠 |
| 两条算法路线的总差（朴素 vs 2/3+3/2） | **4.034e-2** | 里面大部分是**截断** |

**结论**：截断的代价比它顺手消掉的混叠**还大 3 倍**（`decay` 从 0.5 到 2.5，这个比值
稳定在 **2.10 / 3.13 / 5.65 / 6.74**）。"去混叠改善精度"这句话必须说清报的是哪一笔账。

**正确判据**：四个量分开报（帧 meta 里 `alias_rel` / `alias_low_rel` / `truncation_rel` /
`pad_only_rel` / `naive_vs_dealias_rel` 各自独立），别用"总差"冒充"混叠"。

---

## 6. "3/2 规则必须配 2/3 截断" —— 只补零其实就够了

**现象**：教材口径常写成"先截到 `|k| <= N/3`，再补零到 `M >= 3N/2`"，
于是默认"两者缺一不可"。

**实测**：只补零到**精确** `M = 3N/2`、完全不截断时，相对全带参照的偏差只有
**7.76e-5**，而且残差**全部集中在 `|k| = N/2` 这一条边界模态**上
（`cur_nyquist_rel = cur_low_rel = 6e-7`，其余模态是舍入级）。原因是数学的：
补零后乘积模超过 `M/2` 的部分折回，最小落点是 `M - N >= N/2`，正好在保留带边缘。
2/3 截断的**真正**价值是"不补零也能消混叠"（省 FFT 与内存），代价就是第 5 条里那 3.7e-2。

**正确判据**：本内核默认把 `M` 补到不小于 `3N/2` 的 **2 的幂**（`N = 128` 时是 `2N`），
帧 meta 的 `m_used` 是实际用的 `M`——**它不是 3N/2**，别照抄教科书数字。

## 7. 把能量恒等式残差当成去混叠的证据

**现象**：`R = sum_k kappa_k Im(conj(a_k) w_k)` 是"非线性项该不该守恒能量"的直接度量，
看起来是判定混叠的硬指标。

**实测（`N = 128`、`|a_k| = k^-1`、只换相位）**：全带场（未截断）的残差是
**quad 7.65e-18 / lin 4.05e-3 / rand 7.17e-3**——同一张谱，跨度 **9.4e14** 倍。
而对**已经 2/3 截断**的场，朴素乘积与去混叠乘积的残差都只有 **3.4e-18 / 8.4e-17**：
因为折返落在保留带**之外**，总能量账根本看不到它。

**正确判据**：去混叠的证据是**非线性项自身在保留带里的取值**
（`alias_rel` / `alias_low_rel`），不是能量恒等式残差。残差是相位相关的，不能当判据。

## 8. 在 `t = 1` 上量"空间误差"

**现象**：平流方程取 `c = 1`，跑到 `t = 1`，位移正好一个整周期。

**实测**：`c = 1`、`t = 1` 时精确解与初值的差是 **4.9e-15**，而 `N = 16..128` 的谱方法
误差全部 **≤ 1e-13**（与 `N` 无关！）——图上看像"谱方法和差分的空间误差都消失了"。
换成 `c = 0.85` 才有真实的空间误差（首档 > 1e-4）。

**正确判据**：测空间精度必须选**非平凡位移**，并把位移写进帧 meta
（`shift = c*t`，默认帧是 **0.510**）。`t = 0` 与整周期点都是退化帧。

## 9. 把"斜率很漂亮"当成"阶对了"（窗口的陷阱）

**现象**：谱误差曲线撞上双精度地板后，把地板点一起吃进最小二乘
（内核 `fit_power_law(N, err_spectral, lo=64, hi=256)`）会给出 **p = -12.05、R² = 0.80**
这种"很陡的幂律"；帧里报的 `slope_spectral_trap` 用的是上半窗口（`lo = N_max/2`），
`t = 0.6 / 1.0` 时给 **-1.60 / -1.33**（`R² = 0.09 / 0.06`）——两个窗口都不可信，
这正是本条的重点。差分曲线在小 `N` 段也能给出 **1.669** 的"四阶"。

**实测**：四阶差分在 `N = 16/32/64` 上拟出 **1.669**，在 `N = 128/192/256` 上是
**3.9677**（`R² = 0.99995`）；二阶同理 **1.9704**。每加倍比值是最干净的判据：
差分 **0.657 / 0.5413 / 0.3352 / 0.2548**（趋近 1/4，有下界）、四阶
**0.4355 / 0.2247 / 0.0934 / 0.0638**（趋近 1/16）；谱方法则是
**5.55e-2 / 1.20e-2 / 1.23e-3 / 4.07e-5 / 2.90e-8**——**没有下界**。

**正确判据**：窗口（`N` 范围）、`R²`、用点数必须与斜率一起报；地板以上的点才参与拟合
（帧用 `error_floor_mask` 标出，`n_at_floor` 报第一个撞地板的 `N`）。

## 10. 换到 Chebyshev 就能救非光滑数据

**现象**：Chebyshev 配点是"聚在端点上的"，看起来比等距网格更抗端点奇异。

**实测（三种光滑性各一条）**：`runge`（解析）每加倍比值
**0.0765 / 0.0202 / 0.0045 / 4.8e-4 / 1.9e-5 / 2.2e-7**（严格递减，指数）；
`|x|`（C^0 尖角）误差按 **n^-0.9990** 代数下降（`R² = 0.999999`）；
`sign(x)`（跳变）**1.9944 → 1.9540**，几乎不动。微分矩阵侧的结论一样：
`|x|` 的导数误差在 `n = 16..128` 上是 **2.388 / 2.387 / 2.386 / 2.386**——
`O(1)` 且与 `n` 无关。

**正确判据**：换基不换结论，光滑性决定命运。Chebyshev 的红利来自"用较少的点达到同样的
分辨率"，不来自"绕过光滑性要求"。

## 11. 把一维 Burgers 的 `k^-2` 段读成"湍流惯性区"

**现象**：`n = 128`、`nu = 0.02`、`t = 1.5` 时能谱在窗口 `[3,8]` 上的斜率是
**-2.1994**（`R² = 0.999983`），和三维湍流的惯性区指数"一样漂亮"。

**实测**：同一算例的能流峰值 `max Pi = 0.175`，而耗散率 `eps = 0.206`，
比值只有 **0.85**；能流末端 **-1.7e-2**（本该精确回落到 0）。
把黏性压到 `nu = 0.002`（`n = 128`、`t = 1.5`）：能流末端 **-4.280**、收支残差 **1.605**、
能量从 **0.500 涨到 0.840**——这是网格激波 + 高波数堆积的数值现象。
收支残差随 `nu` 单调变差：**1.35e-3 / 6.51e-3 / 3.45e-2 / 8.30e-2**（`nu = 0.03/0.02/0.01/0.005`）。

**正确判据**：一维 Burgers 的 `k^-2` 段是**激波**的谱；"惯性区"的判据是
`Pi(k) ≈ eps` 且能流末端回落到 0，还要看 `k_d = 1/sqrt(nu*t)` 与 2/3 带边缘谁先截断
（本帧默认 `k_d = 5.77`，窗口上界 8 由 `1.5*k_d` 给出）。能量收支闭合才是"算对了"的证据。

## 12. 以为去混叠总能改善能量守恒

**现象**：默认说法是"伪谱法必须去混叠，否则能量不守恒"。

**实测**：`n = 128`、`nu = 0.02`、`t = 1.5` 时，去混叠与朴素乘积两种算法的总能量
相对差只有 **2e-4**，收支残差是 **5.9e-3 vs 2.8e-3**——**朴素的那个还更小**；
差别出现在小尺度量上（Enstrophy 差 **3.5%**、`max|du|/|u| = 3.9e-2`）。
只有在欠分辨时才在能量账上现形（`n = 128`、`nu = 0.005`、`t = 1.5`：Enstrophy 差 **6.5 倍**、
收支残差 **0.58 vs 1.19**）。

**正确判据**：分辨良好时，去混叠改善的是**非线性项与谱细节**；拿"能量守恒改善了多少"
当卖点，在这个算例里会被实测数字当场反驳。
