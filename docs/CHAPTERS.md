# 交互式数值方法实验室 · 章节与可视化总纲

> **一句话目标**：把数值分析从纸面公式变成可以拖着看它收敛、看它发散、看它撒谎的东西。
>
> **规模**：28 章 / 6 大部分 / 115 个交互可视化。
> **每章产出**：推导笔记 + 核心实现 + 交互可视化 + 数值断言 + 防误导分析（五件套）。

---

## 0. 目标与非目标

**目标**

1. 每个概念都有**可交互实验**：能拖参数、能播放时间、能看到失败，而不是一张静态图。
2. 每个可视化背后都有**可执行的数值断言**，杜绝"好看但算错"。
3. 每个概念至少四种视角：**几何 / 代数 / 误差 / 极限**。
4. 每章产出可导出的讲义与动画，最终汇成一部可导航的交互教材。

**非目标**

- 不做教学 SaaS、不做账号系统、不做部署上线。
- 不追求覆盖面，宁可深挖一个概念的四种视角，也不浅尝十个概念。
- **不用现成求解器替代自研实现**。SciPy / NumPy / PyTorch 只作为对拍参照物存在。

## 2. 验证框架

### 三类断言

| 类型 | 内容 | 判定方式 |
|---|---|---|
| **A 解析对拍** | 与解析解或精确求解器比较，误差随 h / N 的**阶数必须等于理论阶** | 双对数斜率拟合，落在理论阶 ±0.1 |
| **B 不变量** | 守恒量（质量/能量/动量）、正交性、对称性、单调性 | 落在机器精度或声明容差内 |
| **C 收敛率** | 迭代法收敛因子、特征值误差界、稳定性阈值 | 由脚本自动判定，**不接受人眼看图** |

### 防误导七条规则

1. 坐标轴**不得自动裁剪**以隐藏发散；越界必须显式标记为"溢出"。
2. 双对数图必须同时画出**实测拟合斜率**与**理论斜率**两条参考线。
3. 所有"看起来很准"的图旁边必须同时给出**误差场 / 残差场**。
4. 自适应坐标轴与固定坐标轴必须明确标注，切换时给视觉提示。
5. 可视化数据一律来自 `numcore`（后端精确计算），前端只做渲染与插值，不得自行重算物理量。
6. 每个可拖参数必须标注**理论临界值**（如 r = 1/2、CFL = 1、r = 1/2 的热方程阈值），越界即提示。
7. 每个可视化必须附一段「它会怎样骗你」，例如固定尺度下看着收敛、实际在缓慢发散。

## 5. 逐章清单

### Part I｜基础与数值线性代数

#### 1.1 浮点数、误差传播与问题条件
- **推导要点**：IEEE-754 表示与舍入单位 u；前向误差与后向误差；Wilkinson 后向误差分析；条件数 κ(A) = ‖A‖·‖A⁻¹‖ 与相对误差界；**良态但算法不稳定**与**病态但算法稳定**的区别；灾难性抵消。
- **核心模块**：`numcore/fp/`（浮点模型、有效位追踪）、`numcore/linalg/cond.py`
- **交互可视化**：
  1. 数轴放大镜：连续放大看浮点网格的不均匀间隔，标出 `0.1 + 0.2` 的真实落点。
  2. 灾难性抵消：拖动 a、b 相互靠近，看有效数字一位位消失，剩余位数实时计数。
  3. 条件数椭球：单位球被 A 映射成椭球，拖动扰动 δb 看解 x 的跳变幅度。
  4. 求和顺序实验：`1e16 + 1 + 1 + …` 的朴素求和 vs Kahan 补偿求和，误差同步显示。
- **数值断言**：相对误差 ≤ κ(A)·相对扰动（验证不等式并给出收紧程度）；Kahan 误差 ~ u，朴素求和误差 ~ n·u。
- **难度 / 燃烧量**：低 / ●●○

#### 1.2 线性方程组直接法
- **推导要点**：LU 分解的存在性与唯一性；选主元的必要性（反例构造）；增长因子 ρ 与后向误差界 ‖δA‖ ≤ ρ·u·‖A‖；Cholesky 的正定条件与无主元稳定性；带状与稀疏结构；**消元即图消去**（填充 = 弦化），最小度排序的图论视角。
- **核心模块**：`numcore/linalg/lu.py`、`chol.py`、`sparse.py`、`ordering.py`（RCM、简化 AMD）
- **交互可视化**：
  1. 消元过程热力图：每一步的行操作 + 增长因子与当前残差实时显示。
  2. 单位球的形变：A → L → LU 的几何变形动画，看体积（行列式）如何变化。
  3. 稀疏 spy plot：切换自然序 / RCM / AMD，填充 nnz(L+U) 实时计数。
  4. 主元策略对比：无 / 部分 / 完全主元在同一病态矩阵上的误差与增长因子柱状图。
- **数值断言**：后向误差界；Cholesky 分解残差；不同排序的 nnz 与图论预测一致。
- **难度 / 燃烧量**：中 / ●●●

#### 1.3 最小二乘与正交化
- **推导要点**：正规方程的误差放大（cond(AᵀA) = cond(A)²）；Householder 与 Givens 正交变换；QR 的向后稳定性；SVD 与伪逆；秩亏与截断阈值；列主元 QR 的秩揭示。
- **核心模块**：`numcore/linalg/qr.py`、`svd.py`（Jacobi 与 Golub–Kahan 两版）、`lstsq.py`
- **交互可视化**：
  1. 三维投影动画：向量 b 投影到 A 的列空间，残差垂直于子空间（正交性肉眼可见）。
  2. 精度对决：cond(A) 从 10² 扫到 10¹²，正规方程与 QR 的误差曲线分道扬镳。
  3. 奇异值谱与截断：拖动截断阈值看解范数与残差的权衡曲线。
  4. 解的不确定扇面：等残差谷底上的解集合随条件数张开。
- **数值断言**：Aᵀr = 0；QR 解与 SVD 解一致；正规方程误差 ~ κ²，QR 误差 ~ κ。
- **难度 / 燃烧量**：中 / ●●●

#### 1.4 特征值、伪谱与非正规性
- **推导要点**：幂法收敛率 |λ₂/λ₁| 与收敛性证明；反迭代与位移策略；QR 算法收敛到 Schur 形；Lanczos / Arnoldi 三项递推与 Krylov 子空间；非正规矩阵的 ε-伪谱定义与谱的"膨胀"；瞬态增长 ‖Aᵏ‖ 与 Kreiss 常数。
- **核心模块**：`numcore/linalg/eigen.py`（power、inverse、QR、Lanczos、Arnoldi）、`pseudospec.py`
- **交互可视化**：
  1. 幂法对齐动画：向量反复乘 A，旋转+拉伸直到对齐主特征向量，Rayleigh 商收敛曲线并排。
  2. Schur 收敛热力图：QR 迭代中次对角元指数衰减为 0。
  3. **伪谱等高线**：拖动 ε 看特征值"云雾"扩散；正规矩阵纹丝不动，非正规矩阵整片亮起。
  4. 瞬态增长：‖Aᵏ‖ 先增后减，与"特征值模预测的单调衰减"形成对比。
  5. GMRES 残差平台与伪谱形状的对应（为 1.5 铺路）。
- **数值断言**：幂法收敛率与 |λ₂/λ₁| 一致；Lanczos 特征值误差落在理论上界内；伪谱边界与解析例子一致。
- **难度 / 燃烧量**：高 / ●●●

#### 1.5 稀疏迭代法与预条件
- **推导要点**：Jacobi / GS / SOR 的迭代矩阵与谱半径决定收敛；CG 的最优性与收敛界 (√κ−1)/(√κ+1)；GMRES 的多项式逼近视角与残差单调性；预条件（Jacobi、SSOR、ILU(k)、AMG 入门）；Krylov 子空间与特征值分布的关系。
- **核心模块**：`numcore/linalg/iterative.py`、`precond.py`、`krylov.py`
- **交互可视化**：
  1. **迭代路径赛跑**：二维椭圆等高线上 Jacobi / GS / SOR / CG / GMRES 的轨迹同图竞速。
  2. 误差的特征分量分解：每个特征方向的误差条形图，看谁先衰减完。
  3. Krylov 子空间逐步扩张（2D/3D 中画出子空间与残差正交性）。
  4. 预条件前后：谱分布散点图 + 收敛曲线联动，条件数实时显示。
- **数值断言**：实测收敛因子与谱半径一致；CG 迭代数 ~ √κ；预条件后条件数下降倍数。
- **难度 / 燃烧量**：高 / ●●●

### Part II｜逼近、积分与变换

#### 2.1 插值与多项式逼近
- **推导要点**：Lagrange 与 Newton 形式、差商；插值误差 f⁽ⁿ⁺¹⁾(ξ)/(n+1)!·∏(x−xᵢ)；Runge 现象与节点分布的关系；Chebyshev 节点的最小最大性质；Lebesgue 常数；重心插值公式的数值稳定性。
- **核心模块**：`numcore/interp/poly.py`（lagrange、newton、barycentric、chebyshev、remez）
- **交互可视化**：
  1. Runge 函数：等距 vs Chebyshev 节点，拖 n 看边缘振荡如何爆发。
  2. Lebesgue 常数随 n 增长：等距的指数爆炸 vs Chebyshev 的对数增长。
  3. 误差沿区间的分布图（不是只看最大误差，而是整条误差曲线）。
  4. 重心公式 vs 直接解范德蒙德系统：误差量级并排对比。
- **数值断言**：插值误差落在理论上界内；重心公式误差 ~ u；Runge 例子发散、Chebyshev 收敛。
- **难度 / 燃烧量**：低 / ●●○

#### 2.2 样条与分段逼近
- **推导要点**：三次样条的 C² 条件导出三对角系统；自然 / 夹持 / not-a-knot 边界；B 样条基与 de Boor 算法；变分性质（在所有插值函数中曲率能量最小）；形状保持与单调性。
- **核心模块**：`numcore/interp/spline.py`
- **交互可视化**：
  1. 拖动控制点实时更新曲线 + 曲率梳（curvature comb）。
  2. C⁰ / C¹ / C² 对比：二阶导的阶梯跳变被画出来。
  3. B 样条支撑区间与节点插入动画（局部修改的局部性）。
  4. 样条 vs 高阶多项式插值：同一数据上的稳定性对比，拖 n 看多项式失控。
- **数值断言**：三对角系统解正确；C² 连续性数值检查；样条曲率能量小于任意同数据插值多项式。
- **难度 / 燃烧量**：中 / ●●○

#### 2.3 正交多项式与函数逼近
- **推导要点**：Gram–Schmidt 与正交多项式；Legendre / Chebyshev / Laguerre 递推关系；最佳一致逼近与 Chebyshev 交错定理；Remez 算法；最小二乘的投影几何；收敛率与函数光滑性的对应（解析函数 → 谱收敛）。
- **核心模块**：`numcore/interp/orthopoly.py`、`approx.py`
- **交互可视化**：
  1. 函数空间投影动画：把函数画成向量，投影到有限维子空间。
  2. 三种函数的收敛率对比：解析函数（指数）、有尖点（代数）、有跳跃（极慢）同图。
  3. 交错点标记：误差曲线上的等幅振荡点闪烁标出。
  4. 正交多项式零点分布随阶数演化（分岔图风格）。
- **数值断言**：正交性 ∫pᵢpⱼ = δᵢⱼ 用高精度求积验证；误差衰减率与理论一致；Remez 结果满足交错性质。
- **难度 / 燃烧量**：中 / ●●●

#### 2.4 数值积分
- **推导要点**：插值型求积与误差项；Newton–Cotes 族；Gauss 求积的 2n−1 次精确度与正交多项式零点；Romberg 外推；奇异性处理与变量替换；自适应求积的误差估计。
- **核心模块**：`numcore/quad/`（trapz、simpson、gauss、romberg、adaptive、tanh-sinh）
- **交互可视化**：
  1. 面积逼近动画：拖 n 看误差，双对数图实时拟合斜率并叠加理论阶参考线。
  2. Gauss 节点 vs 等距节点：位置对比 + 多项式精确度测试（能精确积到几次）。
  3. Romberg 三角表：每一列的收敛阶可视化。
  4. 端点奇异性：tanh-sinh 的指数收敛 vs 等距的代数收敛。
- **数值断言**：实测阶数 = 理论阶；Gauss 精确积分 2n−1 次多项式；Romberg 各列阶数正确。
- **难度 / 燃烧量**：低 / ●●○

#### 2.5 傅里叶分析与 FFT
- **推导要点**：DFT 定义与性质、循环卷积定理；FFT 分治推导与 O(N log N)；混叠机理；泄漏与窗函数旁瓣；Gibbs 现象；谱微分与谱精度。
- **核心模块**：`numcore/transform/fft.py`（radix-2，另加 Bluestein 处理任意长度）、`spectral_utils.py`
- **交互可视化**：
  1. 信号 ↔ 频谱实时联动：拖动基频与各次谐波幅度。
  2. FFT 分治蝴蝶图动画：每一级的蝶形运算逐帧展开。
  3. **混叠演示**：降低采样率，看高频如何折叠回低频（锯齿变慢正弦）。
  4. 泄漏与窗函数：矩形 / Hann / Blackman 的旁瓣对比。
  5. Gibbs 现象：方波截断的过冲稳定在约 9%，拖 N 看它不消失。
- **数值断言**：FFT 与 O(N²) DFT 逐点对拍；卷积定理成立；Parseval 能量守恒。

## 7. 并行化与工作量

每章可拆成 4 个互相独立的子任务：**核心实现 / 前端可视化 / 推导笔记 / 断言与回归测试**。

- 28 章 × 4 ≈ **112 个可并行子任务**
- 依赖图的边很少：Part I 是全项目地基（尤其 1.1、1.2），Part III 之后各章彼此基本独立
- 建议并行宽度：M1 阶段 3–4 个子 agent，M2 之后 8–20 个

**量级估算**

| 项 | 单章 | 全项目 |
|---|---|---|
| 数值核心代码 | 1500–5000 行 | 6–10 万行 |
| 前端可视化代码 | 1200–4000 行 | 4–9 万行 |
| 推导笔记 | 15–40 页 | 500–1000 页 |
| 交互可视化 | 4–5 个 | 115 个 |
| 数值断言 | 20–60 条 | 约 1000 条 |

## 8. 风险与已知坑

| 风险 | 说明 | 对策 |
|---|---|---|
| **前端性能** | 实时 PDE / FEM 求解在浏览器里跑不动 | 关键内核编译到 WebAssembly；或后端预计算帧 + 前端插值回放 |
| **双实现漂移** | TS 版悄悄与 Python 版不一致，可视化就开始撒谎 | CI 中对拍固定基准数据，容差写入仓库 |
| **图好看但算错** | 最危险的失败模式 | 断言框架强制：每条曲线都要有理论参考线或精确解对照 |
| **概念难度过高** | 多重网格、伪谱、伴随容易做成"看不懂的图" | 这三章强制要求给出"逐步点亮"的分步动画，而非一次性呈现 |
| **范围膨胀** | 28 章全做是长期工程 | M1 后设检查点，按兴趣续做，允许砍章 |
| **参考实现依赖** | 一不小心用 SciPy 替代了自研实现 | `numcore/reference/` 是全仓库唯一允许 import SciPy 的目录，用 CI 静态检查强制 |

## 9. 建议的起步顺序

1. **M0 骨架** + `numcore/verify` 断言工具（先有裁判，再有运动员）
2. **1.2 线性方程组直接法** —— 可视化范式最标准（热力图 + spy plot），适合把模板定型
3. **3.2 稳定性与刚性方程** —— 稳定域交互是全书最有说服力的一个可视化，用来验证"可交互性"上限
4. **1.4 特征值、伪谱** —— 数学密度最高，用来验证"推导 + 可视化"能否真正咬合
5. 模板定型后按 Part 顺序铺开，Part III / IV 可与其他部分并行
